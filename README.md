# DonArg — esqueleto del proyecto

Sistema de donaciones, pedidos y objetos encontrados. Es como un marketplace pero para donar o pedir donaciones de objetos. Tambien tiene la parte de objetos encontrados
para publicar cuando se encuentran pertenencias por la via pública.

Stack: Java 17 + Spring Boot 3 en el backend, React en el frontend.

## Estructura

```
donarg/
├── donarg-backend/     -> API REST (Spring Boot 3, Java 17, Maven)
└── donarg-frontend/    -> Cliente web (React + Vite)
```
